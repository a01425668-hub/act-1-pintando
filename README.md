# Actividad 1. Juego Pintando

Este proyecto contiene una versión modificada del clásico videojuego de Paint. El código fuente original usado de base para este proyecto se puede encontrar en [Free Python Games](https://grantjenks.com/docs/freegames/paint.html)

## Modificaciones

* **Cambio 1:** Se agregó el color naranja.
* **Cambio 2:** Se implementó la funcionalidad para crear un círculo.
* **Cambio 3:** Se implementó la funcionalidad para crear un rectángulo.
* **Cambio 4:** Se implementó la funcionalidad para crear un triángulo.

## Ejecutar Localmente

Clona el proyecto

```bash
  git clone https://github.com/a01425668-hub/act-1-pintando.git
```

Ve al directorio

```bash
  cd act-1-pintando
```

Instala las librerías necesarias

```bash
  pip install freegames
```

Ejecuta el código

```bash
  python3 paint.py
```
